Guia de Publicação: Azure Static Web Apps

100% Gratuito usando Azure para Estudantes & GitHub

Com sua conta Azure for Students, você tem acesso gratuito ao Azure Static Web Apps. Siga este passo a passo simples de 4 etapas para colocar este aplicativo no ar:

1

Criar um repositório no GitHub

Acesse o GitHub, crie um novo repositório (público ou privado) com o nome diario-estudos-azure.

Coloque o código deste arquivo salvo como index.html no repositório.

2

Acessar o Portal do Microsoft Azure

Acesse o Portal do Azure com sua conta de estudante.

Na barra de pesquisa do topo, digite Static Web Apps (Aplicativos Web Estáticos) e clique para criar um novo recurso.

3

Configurar o recurso no Azure

  • Assinatura: Escolha Azure for Students.
  • Grupo de Recursos: Clique em "Criar novo" e insira rg-estudos.
  • Nome: Digite meu-diario-de-estudos.
  • Plano: Selecione Free: For hobby or personal projects.
  • Implantação: Selecione GitHub e clique para se autenticar.
  • Repositório: Escolha a sua conta, o repositório diario-estudos-azure e a branch main.
  • Predefinições de Build: Escolha Custom e deixe o "Local do aplicativo" como / (barra).
4

Revisar e Criar

Clique em Revisar + Criar e depois em Criar. Em menos de 2 minutos, o Azure irá compilar o projeto automaticamente e te fornecerá uma URL pública HTTPS gratuita para acessar seu app de qualquer lugar!

Dica Pro: Qualquer alteração ou atualização que você enviar (push) para seu repositório no GitHub atualizará o seu site no Azure automaticamente!
